# AntiManager Site

Public website: https://antimanager.pro
GitHub: https://github.com/AntiManager/AntiManager

## Project Structure

```
AntiManager/
  src/               # Source files
    content/          # Chapter HTML partials (lite content)
    data/             # chapters.json, tools.json, cases.json
    templates/        # base.html, chapter.html
    components/       # header.html, sidebar.html, footer.html
  css/               # Stylesheets
  js/                # JavaScript
  fonts/             # Self-hosted fonts (Inter, Manrope)
  tests/             # Playwright UX tests
  deploy/            # nginx config, deployment scripts
  site/              # Built static site (gitignored, generated by build.js)
  build.js           # Static site builder (Node.js)
  package.json       # npm scripts (build, test)
  playwright.config.js
  deploy.ps1         # Deploy to VPS
```

## Vault Path

Source articles (`.md` files) for book chapters live in the Obsidian vault:
```
C:\Users\USERNAME\Documents\VAULT_DIR\Книга\01_Статьи\
```

Chapters are numbered `XX_Title.md` and map to chapters in `src/data/chapters.json`.

When creating new lite chapter content:
1. Read the source `.md` from `Книга/01_Статьи/`
2. Extract: principle, model/table, thesis excerpt
3. Create interactive widget (diagnostic/calculator)
4. Write HTML partial to `src/content/XX-slug.html`
5. Run `node build.js` to rebuild
6. Run `deploy.ps1` to deploy

## Design System
- CSS Custom Properties with Sajid 4-color HSL formula
- Class-based dark theme (`.dark` on `<html>`)
- Fonts: Inter (body) + Manrope (headings), self-hosted woff2
- Breakpoints: 768px (sidebar collapse), 480px (nav hide)
- Tap targets: 44px minimum (WCAG AAA)

## SSH / Deploy
```
ssh -p 2222 REMOTE_USER@ANTIMANAGER_VPS_IP
nginx container: antimanager-web, root: /home/REMOTE_USER/antimanager/current/
```

## Conventions
- Vanilla HTML/CSS/JS — no frameworks
- Lite-first content: principle + model + thesis + widget + download button
- All 22 chapters indexed, noindex for /about/ removed (has manifesto content)
- Widgets: one question per screen, back button, step counter, progress bar
