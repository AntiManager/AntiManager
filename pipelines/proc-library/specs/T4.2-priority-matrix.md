# T4.2 — Priority matrix (Eisenhower): derivation spec

Status: frozen · Phase 4 (T4.artifacts, sub-plan 03) · English (service doc)

Canonical source: umbrella `1791810263662-artifact-chain-ktk-priority-grid.md`
§5 (matrix table contract, folding, token rules) and §6 (shared execution rules).
This spec makes the derivation of the single priority-matrix artifact
reproducible: from the client ФРПС register (13 role sections) to the unified
`library/artifacts/Приоритеты_руководителей.md` (10 canonical roles).

Format contract (frontmatter, heading, exact table header, cell vocabularies)
lives in `specs/T4.9-artifact-format.md`; the role register lives in
`specs/T4.0-role-archetypes.md` + `role_registry.json`. This spec adds only the
**derivation rules**.

## 1. Purpose and shape

One file, one table per canonical role (10 role sections, order
`ГД, РП, ГИ, ГТ, РК, РС, ГМ, HR, НЦ, НС`). Each section is the Eisenhower
matrix of that role: what is urgent/important, what to delegate, what to
automate or drop. The file answers *how each role spends its managerial
attention*, tied to process codes so every priority is traceable (H7).

## 2. Column schema (source → unified)

The source matrix and the unified artifact share the same six columns; the
unified header is the exact literal in T4.9 §4:

| Column | Rule |
|---|---|
| `Квадрант` | one of the four quadrants (§3); **filled on every row** (the source carries it only on the first row of a group) |
| `Задача` | the priority, de-identified (§6) |
| `Тип` | source type (`Разовый кризис` / `Системный сбой`), `–` when absent |
| `Делегирование` | who does it and under what conditions (§5) |
| `Профилактика / автоматизация` | preventive/automation action, `–` when absent |
| `Связанный процесс (код)` | ≥1 valid library process code (§7) |

## 3. Quadrant rules

Four quadrants, in this canonical order:

1. `Срочно и важно` — crisis. **Type** distinguishes a `Разовый кризис`
   (immediate personal intervention) from a `Системный сбой` (recurring — it
   automatically spawns a root-cause task in quadrant 2).
2. `Важно, но не срочно` — prevention, development, strategy; the growth zone.
3. `Срочно, но не важно` — delegation zone (W3).
4. `Не срочно и не важно` — automate or eliminate zone (W3).

Conflict priority (from the source's general principles, ported into the file's
`## Общие принципы`): safety > quality > plan > budget.

## 4. Role mapping and folding

Source sections are mapped to the register; folding **drops the source section
and re-anchors its process-anchored rows to the target role's matrix**:

- §10 `Оператор` and §11 `Ремонтный персонал` — **dropped** (action roles, not
  owners; T4.0).
- §6 `Начальник ПЭО` → **ГД** (the economic office reports to the director).
- §13 `ИПП` → **РП**; §12 `РПС` → **ГТ**.
- §1 РП, §2 НЦ, §3 ГТ, §4 ГМ, §5 ОТК→**РК**, §7 HR, §8 Мастер→**НС**,
  §9 ГД→**ГД**.

After folding, duplicate `(quadrant, task)` rows are dropped (stable order:
quadrant order, then first occurrence).

**Authored sections.** `ГИ` and `РС` have no source section; they are authored
from the library (T4.0 folds Эколог/Специалист по ОТ into ГИ, начальник
транспортной службы into РС) and anchored to existing codes: ГИ ← INF/ENV/EMG/
HRP-02; РС ← SL_LOG/PLAN-03/HRP/ORG.

## 5. Delegation rule (W3)

Every row in the two «не важно» quadrants carries a **non-empty**
`Делегирование` — a concrete executor with time and authority, or an explicit
replacement/automation plan. The checker warns (W3) if a «не важно» row has an
empty cell. Whenever a role delegates, it keeps control and accountability (the
source's general principle, ported).

## 6. Token rules (H6)

Client/holding tokens are stripped (umbrella §5). The derivation applies
**case-aware** substitutions so the prose stays grammatical:

- `УК` → «головная организация»; `ТД`/`Торговый дом` → «внешний заказчик»;
  `давальческая схема` → «переработка»; `ПС ПП`, `ФРПС` → neutral wording;
  `ПЭО` → «экономическая служба»; `ИПП`, `РПС` → their functional names;
  `Power BI` → «BI-инструмент»; `1С ERP` → «учётная система».
- Hard targets: a parenthetical containing a percentage is removed; a money
  figure is replaced by «установленный лимит» (or marked `ориентир`, T4.0).
- Dates like `01.07.2027` are removed.

## 7. Code-traceability rule (H7)

Every row references ≥1 process code that resolves to a library node (H2). A
source row whose code cell resolves to **no** library node is **dropped**: the
unified artifact contains only priorities anchored in the process library
(gaps = 0). Codes are matched literally, case-sensitive.
