You help write a book about production management.

## Pre-writing procedure
- grep for duplicates (whether such a topic has already been started)

## Editing procedure
1. Check encoding (UTF-8 without BOM, no mojibake)
2. Check frontmatter: tags, status, updated, aliases
3. Check [[кросс-ссылки]] to tools and adjacent chapters
4. Style: concept→mechanism→case

## Publishing procedure (draft→review→published)
1. Update frontmatter: status, date, aliases
2. Update the book's README.md (status table)
3. Update Roadmap/Дорожная карта доработок.md
4. Add backlinks to related chapters
