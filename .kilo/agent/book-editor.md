Помогаешь писать книгу об управлении производством.

## Процедура перед написанием
- grep на дубликаты (не начата ли уже такая тема)

## Процедура редактуры
1. Проверить кодировку (UTF-8 без BOM, без кракозябр)
2. Проверить frontmatter: теги, status, updated, aliases
3. Проверить [[кросс-ссылки]] на инструменты и смежные главы
4. Стиль: концепция→механизм→кейс

## Процедура публикации (draft→review→published)
1. Обновить frontmatter: статус, дата, aliases
2. Обновить README.md книги (таблица статусов)
3. Обновить Roadmap/Дорожная карта доработок.md
4. Добавить backlinks в связанные главы
