---
description: Проверить и исправить битую кодировку в .md файлах vault
---
Ищет файлы с битой кодировкой (UTF-8 double-encoding: русский текст выглядит как «Р”РІР° С‚РёРїР°» вместо «Два типа»).
Исправление: читать как UTF-8 → перекодировать в Windows-1251 → сохранить как UTF-8 без BOM.

Алгоритм для каждого файла:
1. Прочитать байты
2. Если есть BOM (EF BB BF) — пропустить
3. Декодировать как UTF-8 → строка
4. Закодировать как Windows-1251 → байты
5. Сохранить (WriteAllBytes)

Проверить все файлы в:
- Книга/01_Статьи/
- Книга/06 - Черновики глав/
- Roadmap/
